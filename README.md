# 秦声听戏

秦腔、传统戏曲与民族音乐推荐项目，包含网页版和微信小程序版。

## 项目内容

- `web/`：React 网页版，已部署到 Netlify
- `miniprogram/`：微信原生小程序，AppID `wx055093ebba6c7922`
- 20 首公开授权试听曲目
- 每日推荐、搜索、收藏、最近播放和连续播放
